# How to use this course

This course is a **quick-revision resource** for the OS section of your
placement prep. It is deliberately short and to the point: every lesson is the
concept → the key points → a real-world **use case** → **numerical practice**
→ a small **quiz**.

Work through the lessons **in order**:

1. **Processes & Threads** — program vs process vs thread, states, PCB, context switch, threading models.
2. **CPU Scheduling** — FCFS, SJF, SRTF, Round Robin, Priority, MLQ/MLFQ, starvation & aging.
3. **Synchronization** — race conditions, critical section, mutex/semaphore, the classic problems.
4. **Deadlocks** — Coffman's conditions, prevention/avoidance/detection, Banker's algorithm, RAG.
5. **Memory Management** — paging, segmentation, virtual memory, page replacement, thrashing.
6. **File Systems & I/O** — allocation methods, directories, disk scheduling, inodes, fork/exec/wait.
7. **Linux & Debugging** — ps/top/free, /proc, signals, zombies & orphans, strace, the `ls` walkthrough.
8. **IPC & Threads in Practice** — pipes, shared memory, message queues, sockets, thread pools.
9. **Page Replacement Practice** — LRU vs FIFO vs Optimal, Belady's, TLB, a coding exercise.
10. **Final Assessment** — a comprehensive MCQ test across all nine sections.

Every lesson uses **flowchart diagrams** (rendered inline, no downloads) and
**worked numericals** — the kind of numbers you must be able to compute by hand
in an interview. Three lessons also have a small coding exercise (SJF
scheduling, FIFO and LRU page replacement) where the arithmetic is genuinely
worth practicing.
