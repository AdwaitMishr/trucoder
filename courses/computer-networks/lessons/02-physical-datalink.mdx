      The **physical layer** moves raw bits; the **data link layer** turns those bits
      into frames, detects/corrects errors, and controls who talks on the wire.

      ## Transmission media (one line each)

      - **Twisted pair** — cheap copper, used in Ethernet (Cat5e/Cat6) and phones; susceptible to interference.
      - **Coaxial** — shielded copper, cable TV / older Ethernet; better noise immunity than twisted pair.
      - **Fiber optic** — light pulses in glass; very high bandwidth, long distance, immune to EMI.
      - **Radio / wireless** — unguided electromagnetic waves; mobility, but shared, lossy medium.

      ## Error detection

      - **Parity bit** — add 1 bit so the total number of 1s is even (even parity) or odd.
        *Limitation:* detects only an *odd* number of flipped bits — two bit flips cancel out.
      - **CRC (Cyclic Redundancy Check)** — treat the frame as a binary number and divide it
        (mod-2, XOR) by a fixed generator polynomial (e.g. CRC-32). The **remainder is the FCS**
        appended to the frame. The receiver re-divides: a non-zero remainder means corruption.
        Catches *burst* errors up to the polynomial degree — much stronger than parity.
      - **Hamming distance** — number of bit positions two codewords differ in. To detect *d*
        errors you need distance ≥ d+1; to *correct* d errors, distance ≥ 2d+1.
      - **Hamming code** — adds check bits at power-of-2 positions so the receiver can locate
        and fix a single-bit error. For *n* data bits you need *r* check bits where:

        `2^r ≥ n + r + 1`

      ### Worked numerical: Hamming check bits for 8 data bits

      Try r = 3: 2^3 = 8 ≥ 8 + 3 + 1 = 12? **No.** Try r = 4: 2^4 = 16 ≥ 8 + 4 + 1 = 13? **Yes.**
      → **4 check bits** (total codeword 12 bits), enough to correct any single-bit error.

      ## Flow control

      - **Stop-and-wait** — send one frame, wait for ACK, then send the next. Simple but slow:
        the link sits idle for 2 × propagation delay per frame. **Utilization**
        `U = Tt / (Tt + 2Tp)` where Tt = transmission time, Tp = one-way propagation delay.
      - **Sliding window** — sender keeps up to **W** frames in flight without waiting.
        - **Go-Back-N:** on loss, retransmit the lost frame *and everything after it*.
        - **Selective Repeat:** retransmit only the lost frame (receiver buffers out-of-order).

      ## MAC: who talks on the shared medium

      - **CSMA/CD (Ethernet, wired)** — *Carrier Sense Multiple Access with Collision
        Detection*: listen before transmitting; if a collision is detected while sending,
        transmit a **jam signal** and back off for a random time (**exponential backoff**,
        doubling the wait window each retry), then retransmit.
      - **CSMA/CA (WiFi, wireless)** — *Collision Avoidance*: listen before talk, and use
        **RTS/CTS** handshakes to reserve the channel, because radio can't detect collisions
        while transmitting.

      **Use case:** Ethernet NICs use CSMA/CD + CRC (FCS); every WiFi card uses CSMA/CA;
      TCP's reliability relies on the sliding-window idea at the transport layer.

      :::tip
      **Interview question:** Why does WiFi (CSMA/CA) not do collision detection like
      Ethernet (CSMA/CD)? — A radio transceiver cannot listen while it is transmitting
      (the transmitted signal drowns out incoming ones), so collisions are undetectable.
      WiFi therefore *avoids* collisions: listen-before-talk, RTS/CTS reservation, and
      random backoff. Wired Ethernet can monitor voltage on the shared wire, detect the
      collision, jam, and back off.
      :::

      :::tip
      **Interview question:** CRC vs checksum — which is stronger and where is each used?
      — CRC (polynomial division) reliably detects burst errors and protects **Ethernet
      frames** (FCS). The Internet checksum (sum of 16-bit words, ones' complement) is
      cheaper but weaker — it misses some multi-bit errors; it protects IP/TCP/UDP
      *headers* where speed matters and corruption is rarer. Say: "CRC for frames,
      checksum for headers."
      :::
