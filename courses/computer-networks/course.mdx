# How to use this course

Quick-revision resource for the **Computer Networks** section of your placement
prep (section 4 of `interview prep/TODO.md`). Every lesson: concept → key
points → **Use case** → flowchart → **worked numerical** → **interview
questions** → quiz.

Lessons **in order**:

1. **OSI & TCP/IP Models** — 7 layers, TCP/IP 4-layer, encapsulation.
2. **Physical & Data Link** — media, error detection (parity/CRC/Hamming), flow control, CSMA, Ethernet.
3. **Network Layer** — IP addressing, **subnetting & CIDR (code)**, routing, ARP/ICMP/NAT/DHCP.
4. **Transport Layer** — TCP vs UDP, handshakes, flow & congestion control (numericals).
5. **Application Layer** — HTTP/HTTPS, HTTP/1.1 vs 2 vs 3, DNS, SMTP/FTP/SSH, WebSockets vs SSE, REST vs GraphQL.
6. **Network Security** — symmetric/asymmetric crypto, TLS (incl. 1.3), firewalls/VPNs, common attacks.
7. **Debugging & Real-World Networking** — ping/traceroute/dig/curl -v/tcpdump, layered troubleshooting.
8. **Networking in System Design** — DNS at scale (TTL, anycast), CDNs, L4 vs L7 load balancers.
9. **Final Assessment** — comprehensive MCQ/MSQ exam across all eight sections.
