      # Minimal Rotation — the lexicographically smallest cyclic shift

      A **rotation** of a string moves characters one at a time from the front
      to the back. The rotations of `acab` are `acab`, `caba`, `abac` and
      `baca`. Your task: print the **lexicographically minimal rotation**.

      ## Restating the goal

      Reading the string circularly, every rotation is just a *different
      starting point* on the circle. So we must find the starting index whose
      length-`n` read is smallest when compared lexicographically. Doubling the
      string, `s + s`, makes each rotation a contiguous substring of length `n`
      — a handy view used by every approach.

      ## Booth's algorithm, O(n)

      Booth's algorithm finds the minimal rotation in linear time by keeping
      **two candidate starting indices `i` and `j`** plus a matched length `k`,

      - Compare the rotations starting at `i` and `j` character by character
        (offset `k`). While equal, advance `k`.
      - On the first differing character, the *worse* rotation's entire block
        of `k+1` starting positions is provably non-minimal, so it jumps past
        them (`i` or `j` advances by `k+1`), and `k` resets to `0`.
      - The process never compares a character more than once overall, giving
        `O(n)`.

      At the end, whichever index is smaller is the minimal rotation's start.

      ## Complexity

      - Booth: `O(n)` time, `O(n)` space (for the doubled string).
      - Duval / Lyndon-factorization alternative: also `O(n)`.

      :::tip
      **Interview tip:** Minimal rotation is the canonical "linear-time string
      comparison on a circle" question. Booth's jumping-candidate idea (how two
      candidates "prune" a block of starts at once) is widely reusable and a
      great thing to have memorized.
      :::

      # The Problem

      A rotation of a string can be generated by moving characters one after
      another from the beginning to the end. Determine the lexicographically
      minimal rotation.

      ## Input

      The only input line contains a string of length `n`. Each character is
      one of `a`–`z`.

      **Constraints:** `1 <= n <= 10^6`

      ## Output

      Print the lexicographically minimal rotation.

      ## Sample

      **Input:**
      ```
      acab
      ```
      **Output:**
      ```
      abac
      ```

      ### Solution — progressive tiers

      **① Brute force — build and compare every rotation, O(n²)**

      For each start `i`, build `s[i..] + s[0..i-1]` and compare it with the
      current best. `O(n)` rotations × `O(n)` comparison = `O(n²)`; for
      `n = 10^6` that is `10^12` — far too slow.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;
      int main(){
          ios::sync_with_stdio(false); cin.tie(0);
          string s; cin>>s; int n=s.size();
          string best=s;
          for(int i=1;i<n;i++){
              string r=s.substr(i)+s.substr(0,i);
              if(r<best) best=r;
          }
          cout<<best<<"\n";
          return 0;
      }
      ```

      *`O(n²)` time. Too slow for `n = 10^6`.*

      **② Optimization — Booth's algorithm, O(n) (optimal)**

      Use two candidate starts `i`, `j` and a matched length `k`; on the first
      mismatch, the worse block of `k+1` starts is pruned at once. Compiled and
      run against the sample below.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;
      int main(){
          ios::sync_with_stdio(false); cin.tie(0);
          string s; cin>>s; int n=s.size();
          string t=s+s;
          int i=0,j=1,k=0;
          while(i<n && j<n && k<n){
              char a=t[i+k], b=t[j+k];
              if(a==b) k++;
              else if(a>b){ i=i+k+1; if(i<=j) i=j+1; k=0; }
              else { j=j+k+1; if(j<=i) j=i+1; k=0; }
          }
          int start=min(i,j);
          cout<<t.substr(start,n)<<"\n";
          return 0;
      }
      ```

      *`O(n)` time, `O(n)` space. The recommended solution.*

      **③ Alternative — Duval's algorithm (Lyndon factorization), O(n)**

      A *Lyndon word* is a string strictly smaller than all of its rotations,
      so the minimal rotation of `s` is the start of the last Lyndon factor of
      `s + s` (Duval's factorization is linear). A different classic, same
      linear bound.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;
      int main(){
          ios::sync_with_stdio(false); cin.tie(0);
          string s; cin>>s; int n=s.size();
          string t=s+s;
          int i=0, ans=0;
          while(i<n){
              ans=i;
              int j=i+1, k=i;
              while(j<n && t[k]<=t[j]){
                  if(t[k]<t[j]) k=i; else k++;
                  j++;
              }
              while(i<=k) i += j-k;
          }
          cout<<t.substr(ans,n)<<"\n";
          return 0;
      }
      ```

      *`O(n)` time, `O(n)` space. Uses the Lyndon-factorization pointer
      technique rather than two explicit candidates.*

      # Code logic

      - **Doubled lookup.** `t = s + s` so both candidates read `t[i+k]` /
        `t[j+k]` — no modulo arithmetic needed inside the loop.
      - **Three-state step.** `a == b`: extend the equal run `k`. `a > b`:
        rotation `i` is worse, so its block of starts `i..i+k` is all beaten by
        `j` — jump `i += k+1` (bumped past `j` if it would collide). `a < b`:
        symmetric jump for `j`.
      - **Resetting `k`.** After any jump, start comparing afresh with `k = 0`.
      - **Answer index.** The survivor `min(i, j)` is the start of the minimal
        rotation; print `t.substr(start, n)`.

      - `i=0, j=1, k=0`. `t[0]='a'` vs `t[1]='c'`: `'a' < 'c'` → worse is `j`;

      - `i=0, j=2, k=0`. `t[0]='a'` vs `t[2]='a'`: equal → `k=1`.
        `t[1]='c'` vs `t[3]='b'`: `'c' > 'b'` → worse is `i`;
        `i = 0+1+1 = 2`, and `i<=j` so `i = j+1 = 3`. `k=0`.
      - `i=3, j=2, k=0`. `t[3]='b'` vs `t[2]='a'`: `'b' > 'a'` → worse is `i`;
        `i = 3+0+1 = 4` → loop's `i<n` stops.

      Survivors `{i=4, j=2}` → `start = min(4,2) = 2`. `t.substr(2,4) = "abac"`.
