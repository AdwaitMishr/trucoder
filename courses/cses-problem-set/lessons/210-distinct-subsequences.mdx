      # Distinct Subsequences — DP with last occurrence

      Count the number of **different** strings you can form by deleting any
      number of characters (keeping the relative order of the rest). The number
      can be huge, so print it modulo `10^9+7`.

      This is a clean **DP** where the only hard part is not counting duplicates.
      If we appended a new character `c` to every existing subsequence, almost
      everything is new — except the subsequences that were *already* created the
      last time `c` appeared. So the recurrence subtracts exactly those repeats.

      ## The recurrence (counting the empty subsequence too)

      Let `dp[i]` = number of distinct subsequences of the prefix of length `i`
      **including** the empty string, and `last[c]` = the previous (1-indexed)
      position where character `c` occurred.

      ```
      dp[0] = 1                                  // only the empty subsequence
      dp[i] = 2 · dp[i-1]                        // append s[i-1] to every subseq
              − dp[ last[ s[i-1] ] − 1 ]         // remove repeats from the prior c
      ```

      The subtracted term: at the *previous* occurrence of `c` (position `p`), the
      new subsequences ending in `c` were `dp[p-1]` of them — appending `c` to each
      distinct subsequence of the prefix before `p`. Those are exactly the ones
      we are about to duplicate.

      **What to print:** the problem's sample pins the answer on the **non-empty**
      subsequences, so output `(dp[n] − 1) mod`. (If the empty string were counted,
      the sample `"aybabtu"` would read `104`, but CSES prints `103`.)

      **Complexity.** `O(n)` time — the intended solution; no duplicate
      enumeration needed.

      :::tip
      **Interview tip:** "count distinct subsequences / distinct strings you can
      delete characters to form" is the classic trigger for the
      `dp[i] = 2·dp[i-1] − dp[last−1]` recurrence. A strong signal is the same
      trick used for k-subsets / edit-distance duplicates. Be ready to explain
      *why* subtracting `dp[last−1]` is enough — that is the question interviewers
      probe.
      :::

      # The Problem

      You are given a string. You can remove any number of characters from it,
      but you cannot change the order of the remaining characters.

      How many different strings can you generate?

      ## Input

      The first input line contains a string of size `n`. Each character is one
      of `a–z`.

      **Constraints:** `1 ≤ n ≤ 5·10^5`.

      ## Output

      Print one integer: the number of strings modulo `10^9+7`.

      ## Sample

      **Input:**
      ```
      aybabtu
      ```
      **Output:**
      ```
      103
      ```

      ### Solution — progressive tiers

      **① Brute force — generate every subsequence into a set, O(2^n)**

      Enumerate all `2^n` ways to keep/drop each character, insert the non-empty
      results into a set, count. Correct but exponential — impossible for
      `n = 5·10^5`.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;
      string s; set<string> se;
      void rec(int i, string cur){
          if(i == (int)s.size()){ if(!cur.empty()) se.insert(cur); return; }
          rec(i+1, cur);              // skip s[i]
          cur.push_back(s[i]);
          rec(i+1, cur);              // keep s[i]
      }
      int main(){
          cin >> s;
          rec(0, "");
          cout << se.size() << "\n";
          return 0;
      }
      ```
      *O(2^n · n) — correct, impossible at scale.*

      **② Optimization — DP with last occurrence, O(n)**

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;
      int main(){
          ios::sync_with_stdio(false); cin.tie(nullptr);
          const long long MOD = 1000000007LL;
          string s; cin >> s;
          int n = (int)s.size();
          vector<long long> dp(n+1, 0);
          dp[0] = 1;                                // empty prefix -> empty subsequence
          vector<int> last(26, 0);                  // previous 1-based position (0 = none)
          for(int i = 1; i <= n; i++){
              int c = s[i-1] - 'a';
              dp[i] = (2 * dp[i-1]) % MOD;          // append s[i-1] to every subseq
              if(last[c] > 0)
                  dp[i] = (dp[i] - dp[last[c]-1] + MOD) % MOD;  // drop repeats from prior c
              last[c] = i;
          }
          cout << (dp[n] - 1 + MOD) % MOD << "\n";  // exclude the empty subsequence
          return 0;
      }
      ```
      *O(n) time, O(n) memory — the intended solution.*

      **③ Further optimization — none needed**

      `O(n)` is optimal; the matching alphabet is fixed (`26`).

      **④ Alternative — per-ending-character DP, O(n)**

      Track `total` (# distinct subsequences incl. empty) and `endc[c]` (# distinct
      subsequences ending with `c`). Each new `c` adds `total − endc[c]` fresh
      subsequences ending in `c`.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;
      int main(){
          ios::sync_with_stdio(false); cin.tie(nullptr);
          const long long MOD = 1000000007LL;
          string s; cin >> s;
          long long total = 1;                 // including the empty subsequence
          vector<long long> endc(26, 0);       // distinct subsequences ending in c
          for(char ch : s){
              int c = ch - 'a';
              long long add = (total - endc[c] + MOD) % MOD; // new distinct ending in c
              total = (total + add) % MOD;
              endc[c] = (endc[c] + add) % MOD;
          }
          cout << (total - 1 + MOD) % MOD << "\n";  // exclude empty
          return 0;
      }
      ```
      *O(n) — an equivalent DP, arguably easier to state aloud.*

      **Which to use:** ② is the textbook recurrence to hand-write; ④ is nice when
      you prefer to reason in terms of "ending character" contributions.

      # Code logic

      Walking through ②:

      - **`dp[i] = 2·dp[i-1]`.** Every existing distinct subsequence can either
        stay as-is or be extended by `s[i-1]`, so the set doubles.
      - **`− dp[last[c]-1]`.** Extending produces duplicates only for those that
        end with `c` — and all such were born at the *previous* `c` (position
        `p`), where appending `c` to the `dp[p-1]` distinct subsequences generated
        them. Subtracting `dp[p-1]` removes exactly those repeats.
      - **Modulo hygiene.** We subtract then add `MOD` to keep the value
        non-negative; final `(dp[n]-1) mod` drops the empty subsequence to match
        the sample.
