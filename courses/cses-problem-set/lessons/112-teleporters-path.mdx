      # Teleporters Path — Euler path in a directed graph

      A game has `n` levels and `m` one-way teleporters (`a → b`), and you win by
      moving **from level 1 to level n using every teleporter exactly once**.
      This is a **(directed) Euler path / trail**: a single walk that starts at
      vertex `1`, ends at vertex `n`, and uses each *directed edge* exactly once.

      **The technique: degree conditions + Hierholzer on a digraph.** For an
      Euler *path* from `s` to `t` (`s ≠ t`) in a directed graph:

      - **`s`** must have `out − in = 1` (start the extra outgoing edge).
      - **`t`** must have `in − out = 1` (end on the extra incoming edge).
      - **Every other vertex** must be balanced (`in == out`), because each
        visit enters once and leaves once.
      - The edges must also form a single weakly connected piece (so the walk
        can actually reach them all).

      If instead all vertices are balanced, an Euler *circuit* exists; but since
      this problem forces start `1` and end `n` with `1 ≠ n`, we need the
      *path* degree signature above.

      **Why these conditions suffice.** Each unbalanced pair `(out-in=1, in-out=1)`
      can be thought of as one imaginary edge `t → s` turning the whole graph
      into an Euler *circuit*; removing that edge from the circuit leaves exactly
      the `s → t` trail. Then **Hierholzer** (same stack-based DFS as the
      previous two lessons) carves the circuit/path out in `O(n + m)`.

      **Complexity.** One degree scan + one DFS walk → **O(n + m)** time,
      **O(n + m)** space.

      :::tip
      **Interview tip:** directed Euler path tests are a favourite "travel every
      road/one-way street exactly once" framing. The 30-second check is the
      degree signature: exactly one vertex `out-in=1`, exactly one `in-out=1`,
      the rest balanced. If someone hands you "use each edge once, start here end
      there", always compute `in`/`out` first — the answer is often "impossible"
      before you search at all. Hierholzer's stack walk is the standard linear
      construction; expect to reverse the popped path.
      :::

      # Question — Teleporters Path

      A game has `n` levels and `m` teleporters between them. You win the game
      if you **move from level 1 to level n** using **every teleporter exactly
      once**.

      **Constraints**

      - `2 ≤ n ≤ 10^5`, `1 ≤ m ≤ 2·10^5`
      - `1 ≤ a, b ≤ n`; each pair `(a,b)` in the input is distinct

      **Input.** First line: `n m` (levels and teleporters). Then `m` lines,
      each `a b` — a teleporter from level `a` to level `b`.

      **Output.** `m + 1` integers: the sequence of levels visited during the
      game. Any valid solution is accepted. If no solution exists, print
      `IMPOSSIBLE`.

      Sample input:

      ```
      5 6
      1 2
      1 3
      2 4
      2 5
      3 1
      4 2
      ```

      Sample output:

      ```
      1 3 1 2 4 2 5
      ```

      ### Solution — progressive tiers

      **① Brute force — backtracking over trails, exponential**

      From the current level, branch across each unused outgoing teleporter,
      recurse, and confirm success only when all `m` teleporters are used and we
      stand on level `n`. An erased-then-restored adjacency tracks which edges
      remain.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;

      int main() {
          ios::sync_with_stdio(false); cin.tie(nullptr);
          int n, m; cin >> n >> m;
          vector<vector<int>> g(n + 1);
          for (int i = 0; i < m; ++i) { int a, b; cin >> a >> b; g[a].push_back(b); }

          vector<vector<int>> used = g;          // mutable copy of adjacency
          vector<int> path{1};
          function<bool(int,int)> dfs = [&](int u, int usedEdges) -> bool {
              if (usedEdges == m) return u == n; // all teleporters used & at level n
              vector<int> saved = used[u];       // snapshot for rollback
              for (int idx = 0; idx < (int)used[u].size(); ++idx) {
                  int v = used[u][idx];
                  used[u].erase(used[u].begin() + idx);   // "use" the teleporter
                  path.push_back(v);
                  if (dfs(v, usedEdges + 1)) return true;
                  path.pop_back();
                  used[u] = saved;               // restore: try the next branch
              }
              return false;
          };
          if (!dfs(1, 0)) { cout << "IMPOSSIBLE\n"; return 0; }
          for (int i = 0; i < (int)path.size(); ++i) { if (i) cout << " "; cout << path[i]; }
          cout << "\n";
          return 0;
      }
      ```

      **Exponential** (all simple trails from `1`) — correct for tiny inputs, but
      `m · (surviving trails)` explodes long before `m = 2·10^5`. A correctness
      baseline only.

      **② Optimization — degree check + Hierholzer, O(n + m) (submission)**

      Verify the `1 → n` path degree signature, then run the stack-based
      Hierholzer walk starting at `1`. If the walk can't use every edge or
      doesn't end at `n`, print `IMPOSSIBLE`.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;

      int main() {
          ios::sync_with_stdio(false); cin.tie(nullptr);
          int n, m; cin >> n >> m;
          vector<int> out(n + 1, 0), in(n + 1, 0);
          vector<vector<int>> full(n + 1);        // adjacency for the walk
          for (int i = 0; i < m; ++i) {
              int a, b; cin >> a >> b;
              full[a].push_back(b);
              ++out[a]; ++in[b];
          }
          // degree conditions for a path starting at 1 and ending at n
          for (int v = 1; v <= n; ++v) {
              int diff = out[v] - in[v];
              if (v == 1 && diff != 1) { cout << "IMPOSSIBLE\n"; return 0; }
              if (v == n && diff != -1) { cout << "IMPOSSIBLE\n"; return 0; }
              if (v != 1 && v != n && diff != 0) { cout << "IMPOSSIBLE\n"; return 0; }
          }
          // Hierholzer from level 1
          vector<int> it(n + 1, 0);
          vector<int> path, st(1, 1);
          while (!st.empty()) {
              int u = st.back();
              if (it[u] < (int)full[u].size()) {
                  st.push_back(full[u][it[u]++]); // take the next unused out-edge
              } else {
                  path.push_back(u);              // no unused out-edge: seal vertex
                  st.pop_back();
              }
          }
          reverse(path.begin(), path.end());      // path was sealed in reverse
          // must use every edge exactly once and end at level n
          if ((int)path.size() != m + 1 || path[0] != 1 || path.back() != n) {
              cout << "IMPOSSIBLE\n"; return 0;
          }
          for (int i = 0; i < (int)path.size(); ++i) {
              if (i) cout << " ";
              cout << path[i];
          }
          cout << "\n";
          return 0;
      }
      ```

      **O(n + m)** time and space. This is the submission tier.

      **③ Alternative — recursive Hierholzer with an explicit Eulerian pre-check**

      Same logic, but factored: an `isEulerian()` pass validates the degree
      signature and weak connectivity, then a clean recursive `dfs` builds the
      path (which is then reversed). The `path.size() == m+1` guard backstops
      connectivity mistakes.

      ```cpp
      #include <bits/stdc++.h>
      using namespace std;

      int main() {
          ios::sync_with_stdio(false); cin.tie(nullptr);
          int n, m; cin >> n >> m;
          vector<int> out(n + 1, 0), in(n + 1, 0);
          vector<vector<int>> g(n + 1), gr(n + 1);
          for (int i = 0; i < m; ++i) {
              int a, b; cin >> a >> b;
              g[a].push_back(b); gr[b].push_back(a);
              ++out[a]; ++in[b];
          }
          for (int v = 1; v <= n; ++v) {
              int diff = out[v] - in[v];
              if ((v == 1 && diff != 1) || (v == n && diff != -1) ||
                  (v != 1 && v != n && diff != 0)) { cout << "IMPOSSIBLE\n"; return 0; }
          }
          // weak connectivity: all edges reachable along g (ignoring direction)
          vector<char> vis(n + 1, 0);
          queue<int> q; q.push(1); vis[1] = 1;
          while (!q.empty()) {
              int u = q.front(); q.pop();
              for (int v : g[u]) if (!vis[v]) { vis[v] = 1; q.push(v); }
              for (int v : gr[u]) if (!vis[v]) { vis[v] = 1; q.push(v); }
          }
          for (int u = 1; u <= n; ++u)
              if ((int)g[u].size() + (int)gr[u].size() > 0 && !vis[u]) {
                  cout << "IMPOSSIBLE\n"; return 0;   // some edge in a separate piece
              }
          vector<int> it(n + 1, 0), path;
          function<void(int)> dfs = [&](int u) {
              while (it[u] < (int)g[u].size()) dfs(g[u][it[u]++]);
              path.push_back(u);                      // post-order seal
          };
          dfs(1);
          reverse(path.begin(), path.end());
          if ((int)path.size() != m + 1 || path.back() != n) { cout << "IMPOSSIBLE\n"; return 0; }
          for (int i = 0; i < (int)path.size(); ++i) { if (i) cout << " "; cout << path[i]; }
          cout << "\n";
          return 0;
      }
      ```

      **O(n + m)** time and space. Explicit connectivity check plus recursion;
      use the iterative tier ② if deep recursion is a concern on huge chains.

      # Code-logic

      The optimal tier does three small things.

      - **Degree signature.** For each vertex compute `diff = out − in`. Vertex
        `1` must have `diff = 1` (the start emits one unpaired edge), vertex `n`
        must have `diff = −1` (the end absorbs it), everyone else `0`. Any
        violation means no `1 → n` Euler path exists.
      - **The walk (Hierholzer).** `it[u]` points to the next unused out-edge of
        `u`. While the top of an explicit stack still has unused out-edges, push
        the next one; otherwise seal the vertex onto `path` and pop. This
        consumes every out-edge exactly once — `path` is the trail in *reverse*
        (deepest seals first), so `reverse` yields the answer. Because `1` is
        forced to be the single source, starting the walk there reaches
        everything when a solution exists.
      - **Backstop checks.** If fewer than `m + 1` vertices were sealed,
        `path.size() != m + 1` — the edges were not all in one connected piece
        (e.g. teleporters forming a separate cycle unreachable from `1`), so it
        is `IMPOSSIBLE`. Likewise a path that doesn't end on `n` can't satisfy
        the win condition. These two checks make the solution robust even
        against a graph that passes the degree scan but splits into pieces.

      # Walkthrough

      **Input (sample):**

      ```
      5 6
      1 2
      1 3
      2 4
      2 5
      3 1
      4 2
      ```

      **Degrees:**

      | level | out | in | out−in |
      |-------|-----|----|--------|
      | 1 | 2 | 1 | +1 ✓ start |
      | 2 | 2 | 2 | 0 ✓ |
      | 3 | 1 | 1 | 0 ✓ |
      | 4 | 1 | 1 | 0 ✓ |
      | 5 | 0 | 1 | −1 ✓ end |

      Signature matches (level `1` is +1, level `n=5` is −1, rest balanced), so
      an Euler path exists.

      **Hierholzer from 1** (one valid run, `st` → sealed `path`):

      | top | takes | st | seal order (reversed later) |
      |-----|-------|-----|------------------------------|
      | 1 | 1→2 | [1,2] | |
      | 2 | 2→4 | [1,2,4] | |
      | 4 | 4→2 | [1,2,4,2] | |
      | 2 | 2→5 | [1,2,4,2,5] | |
      | 5 | — | [1,2,4,2] | seal 5 |
      | 2 | — | [1,2,4] | seal 2 |
      | 4 | — | [1,2] | seal 4 |
      | 2 | — | [1] | seal 2 |
      | 1 | 1→3 | [1,3] | |
      | 3 | 3→1 | [1,3,1] | |
      | 1 | — | [1,3] | seal 1 |
      | 3 | — | [1] | seal 3 |
      | 1 | — | [] | seal 1 |

      Sealed (reverse order): `5 2 4 2 1 3 1` → **reversed: `1 3 1 2 4 2 5`**.

      Verify: `1→3`, `3→1`, `1→2`, `2→4`, `4→2`, `2→5` — all six teleporters
      exactly once, start `1`, end `5` (= n). **Expected `1 3 1 2 4 2 5` —
      Actual `1 3 1 2 4 2 5`. Match.**

      **An impossible case:** add nothing but flip `1→2` to self-balanced with no
      source (e.g. only edges `1→2, 2→1`) — then `out−in` is `0` everywhere,
      vertex `1` is not `+1`, so the degree gate prints `IMPOSSIBLE` (such a
      graph has an Euler *circuit*, but not a `1 → n` path when `n ≠ 1`).
