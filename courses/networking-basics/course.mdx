# How to use this course

Networking is full of "aha, it's just arithmetic" moments, and the fastest way
to lock them in is to write the code yourself. Each lesson here is a small
problem you solve with a `solve(...)` function — no routers, no cables, just
the bits.

Work through the lessons **in order**. They build a chain:

1. Validate an IPv4 address.
2. Turn it into one 32-bit number.
3. Translate a CIDR prefix into a subnet mask.
4. Count the addresses in a block.
5. Name the classful network class.

By the end you will read `192.168.1.1/24` as *"a 32-bit number, sliced into
network + host parts by a 24-bit mask"* — which is the foundation of subnetting.

## The roadmap

| # | Lesson | The idea it introduces |
|---|--------|------------------------|
| 1 | IPv4 validation | well-formedness, octets 0–255 |
| 2 | IPv4 to integer | one 32-bit big-endian number |
| 3 | CIDR → subnet mask | prefix length → mask |
| 4 | Block size | `2^(32 − prefix)` addresses |
| 5 | Classful class | legacy A/B/C/D/E split |
