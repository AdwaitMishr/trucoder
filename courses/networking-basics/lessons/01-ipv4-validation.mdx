solution: |
  def solve(ip: str) -> bool:
      parts = ip.split(".")
      if len(parts) != 4:
          return False
      for p in parts:
          if not p.isdigit():
              return False
          if not 0 <= int(p) <= 255:
              return False
      return True

An IPv4 address is just four numbers separated by dots. The whole trick is
being careful about what "valid" means.

## The shape

`192.168.1.1` is four octets: `192`, `168`, `1`, `1`. A validator has to check
two things for each octet:

- it contains **only digits** (no letters, no signs),
- its numeric value is **0 to 255** inclusive.

:::tip
The most common bug is a string like `1..2.3` — two dots in a row produce an
empty octet. `split(".")` will happily give you `["1", "", "2", "3"]`, so an
empty string must fail your digit check.
:::

## Try it

Write `solve` to return `true` only for a well-formed address. The hidden tests
throw the usual offenders at it: too few octets, letters, empty parts, and
negative numbers.
