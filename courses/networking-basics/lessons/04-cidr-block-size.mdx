A `/24` block isn't 24 addresses — it's `2^(32 − 24) = 2^8 = 256`. Each host
bit doubles the size of the block. This is pure powers of two.

## The rule

`/n` leaves `32 − n` bits for hosts. The block has:

```
2^(32 − n)   addresses
```

| prefix | host bits | addresses |
|--------|-----------|-----------|
| /24    | 8         | 256       |
| /16    | 16        | 65,536    |
| /0     | 32        | 4,294,967,296 (the whole IPv4 space) |

:::warning
`/0` gives `2^32 = 4294967296`, which **overflows a Java `int`**. Return a
`long` in Java.
:::

## In code

`2^(32 − n)` is a single bit shift: `1 << (32 − n)`. That's the whole problem.
No loop needed.
