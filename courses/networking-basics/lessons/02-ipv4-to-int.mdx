Every IP address you've ever seen is secretly one 32-bit integer. This lesson
makes that visible.

## One number, four bytes

`192.168.1.1` in binary is:

```
11000000 . 10101000 . 00000001 . 00000001
```

Push those four 8-bit chunks together and you get a single 32-bit number:

```
11000000101010000000000100000001  =  3232235777
```

This is **big-endian**: the leftmost octet is the most significant byte.

:::warning
The result can be up to `2^32 − 1 = 4294967295`, which is **larger than a Java
`int`** (max 2147483647). Return a `long` in Java, or the high bits wrap around
to a negative number.
:::

## The formula

Give each octet a name — `a.b.c.d` — and shift each into its own byte:

`(a << 24) | (b << 16) | (c << 8) | d`

`<< 24` puts `a` at the top byte, `<< 16` puts `b` next, and so on. The `|`
stitches them together.
