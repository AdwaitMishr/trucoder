  def solve(n: int) -> str:
      mask = 0xFFFFFFFF if n == 32 else (0xFFFFFFFF << (32 - n)) & 0xFFFFFFFF
      return ".".join(str((mask >> shift) & 0xFF) for shift in (24, 16, 8, 0))

`/24` means "the first 24 bits are the network, the rest are the host." The
**subnet mask** is the same idea written as an address: a 1-bit for every
network bit, a 0-bit for every host bit.

## From prefix to mask

A `/24` mask is 24 ones followed by 8 zeros:

```
11111111 11111111 11111111 00000000   =   255.255.255.0
```

So the recipe is: build the integer `0xFFFFFFFF`, shift left by `32 − n` to
clear the host bits, then split into four octets.

:::tip
For `/32` (all ones) your shift becomes `<< 0`, which is fine — but the
`& 0xFFFFFFFF` mask keeps the value in range in languages where a left shift of
a signed number can overflow or sign-extend.
:::

## Splitting the octets

Given one 32-bit `mask`, each octet is `(mask >> (8 * position)) & 0xFF` for
positions 24, 16, 8, and 0. `& 0xFF` keeps only the lowest 8 bits.
