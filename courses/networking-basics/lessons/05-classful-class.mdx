  def solve(ip: str) -> str:
      first = int(ip.split(".")[0])
      if first <= 127:

      if first <= 191:

Before CIDR, the IPv4 space was split into fixed classes based on the leading
bits of the address. Knowing how to read the class is a useful mental shortcut
for identifying familiar ranges.

## The split

The **first octet** decides the class:

| class | first octet | example range |
|-------|-------------|---------------|
| A | 0–127 | `10.x.x.x`, `127.x.x.x` |
| B | 128–191 | `172.16.x.x` |
| C | 192–223 | `192.168.x.x` |
| D | 224–239 | multicast (`224.0.0.x`) |
| E | 240–255 | reserved |

:::tip
Test your boundaries with `127.0.0.1` (still class **A**) and `128.0.0.1` (the
lowest class **B**) — they sit exactly on the knife's edge and catch off-by-one
bugs.
:::

## Only the first octet

Parse just the first number and compare it against the four thresholds in
order. Everything else in the address is irrelevant to the class.
