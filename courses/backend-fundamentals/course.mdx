# How to use this course

This course is distilled from **your own Obsidian notes**
(`notes/v1/Backend/01.md … 09 Caching.md`) and rebuilt as interactive lessons.
Every theory lesson keeps the note's core content, adds **use cases**, an
**e-commerce example**, **interview questions**, and a quiz.

The second half is the special part: a complete **e-commerce backend project**
built lesson by lesson, **test-first**. Each project lesson (10–13) defines
ONE real module — a service, a controller pair, a middleware factory, a
config util — with an exact **module contract** (exports, signatures,
behavior), the **full visible `node:test` suite** that ships with the project
in `tests/`, and the **wiring** that plugs the module into the running
Express app. The platform grades the lesson quizzes; the real deliverable is
making `npm test` go green against the shipped project's visible tests.
**All test cases are visible** — nothing hidden.

Lessons **in order**:

1. **Backend Basics** — what a backend is, the end-to-end request lifecycle, why centralized state.
2. **HTTP** — methods, status codes, headers, request/response anatomy, statelessness.
3. **Routing** — routes, params, query strings, 404s.
4. **Request Context & Controllers** — middleware chain, controller pattern, req/res.
5. **Validation & Transformations** — input validation, sanitization, DTOs, error responses.
6. **Auth** — sessions vs JWT vs cookies, hashing, stateful vs stateless, OAuth/API keys.
7. **API Design** — REST, resource naming, versioning, errors, pagination, idempotency.
8. **Database: PostgreSQL** — modeling an e-commerce schema, SQL, transactions, connection pooling.
9. **Caching** — cache-aside, Redis, TTL, invalidation, hot product catalog.
10. **Project 1: Cart Domain** — cart service (`addItem`/`lineTotal`/`cartTotal`): module contract + visible test suite.
11. **Project 2: Checkout Pipeline** — order service + controller (201 / 409 / 402 / 200 replay): contract + visible test suite.
12. **Project 3: Rate Limiter & Middleware** — sliding-window middleware (429 + Retry-After): contract + visible test suite.
13. **Project 4: Assembly & Docker** — the full Express app, Dockerfile, docker-compose, API walkthrough + config validation: contract + visible test suite.
14. **Final Assessment** — comprehensive exam across all thirteen lessons.
