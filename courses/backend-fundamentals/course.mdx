# How to use this course

This course is distilled from **the author's Obsidian notes** and rebuilt as
interactive lessons. Every theory lesson keeps the note's core content, adds
**use cases**, an **e-commerce example**, **interview questions**, and a quiz.

The second half is the special part: a complete **e-commerce backend project**
built lesson by lesson in **LeetCode style** — each project lesson has a
problem statement and deliverables, and a graded exercise that runs in the
**Node.js Docker sandbox**. **All test cases are visible** — nothing hidden.

Lessons **in order**:

1. **Backend Basics** — what a backend is, the end-to-end request lifecycle, why centralized state.
2. **HTTP** — methods, status codes, headers, request/response anatomy, statelessness.
3. **Routing** — routes, params, query strings, 404s.
4. **Request Context & Controllers** — middleware chain, controller pattern, req/res.
5. **Validation & Transformations** — input validation, sanitization, DTOs, error responses.
6. **Auth** — sessions vs JWT vs cookies, hashing, stateful vs stateless, OAuth/API keys.
7. **API Design** — REST, resource naming, versioning, errors, pagination, idempotency.
8. **Database: PostgreSQL** — modeling an e-commerce schema, SQL, transactions, connection pooling.
9. **Caching** — cache-aside, Redis, TTL, invalidation, hot product catalog.
10. **Project 1: Cart Domain** — cart service, utils, line totals (graded exercise).
11. **Project 2: Checkout Pipeline** — validation → stock → payment → order, idempotency (graded exercise).
12. **Project 3: Rate Limiter & Middleware** — auth + rate-limit middleware chain (graded exercise).
13. **Project 4: Assembly & Docker** — the full Express app, Dockerfile, docker-compose, API walkthrough (graded exercise).
14. **Final Assessment** — comprehensive exam across all thirteen lessons.
