# How to use this course

Quick-revision resource for the **DBMS & SQL** section of your placement prep
(section 5 of `interview prep/TODO.md`). Every lesson: concept → key points →
**Use case** → flowchart → **interview questions** → quiz. SQL is taught with
real queries in fenced code blocks — read them like the docs you wish existed.

Lessons **in order**:

1. **Core Concepts** — DBMS vs file system, ACID (with examples), 3-tier architecture, schema levels.
2. **ER & Relational Model** — entities/attributes/relationships, cardinality, ER→relational, keys.
3. **Normalization** — functional dependencies, 1NF/2NF/3NF/BCNF, denormalization, lossless decomposition.
4. **SQL** — DDL/DML, SELECT, joins, subqueries, GROUP BY/HAVING, window functions, indexes, views.
5. **Transactions & Concurrency** — states, dirty/phantom/non-repeatable reads, isolation levels, 2PL, deadlocks.
6. **Indexing & Storage** — B-tree vs B+ tree, clustered vs non-clustered, hashing, query optimization.
7. **SQL Interview Patterns** — second-highest, top-N per group, anti-join, NULL traps, running totals, division.
8. **SQL vs NoSQL & CAP** — comparison table, CAP, ACID vs BASE, Redis and the NoSQL families.
9. **PostgreSQL, MySQL & Query Tuning** — engine differences, EXPLAIN, CTEs.
10. **Final Assessment** — interview-favourite questions + comprehensive MCQ/MSQ exam across lessons 1–9.
