solution: |
  def solve(text1: str, text2: str) -> int:
      m, n = len(text1), len(text2)
      dp = [[0] * (n + 1) for _ in range(m + 1)]
      for i in range(1, m + 1):
          for j in range(1, n + 1):
              if text1[i - 1] == text2[j - 1]:
                  dp[i][j] = dp[i - 1][j - 1] + 1
              else:
                  dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
      return dp[m][n]

The first *string* DP. The state is a pair of positions — one in each string.
The key trick: when the current characters match you get a free extension; when
they do not, you drop a character from one side and keep the better result.

## Two positions = two dimensions

Let `dp[i][j]` = LCS length of `text1[:i]` and `text2[:j]`. Two indices because
both strings shrink independently. This is the standard shape for any two-string
DP problem (edit distance is next).

## The match case

If `text1[i-1] == text2[j-1]`, these characters pair up, so:

```
dp[i][j] = dp[i-1][j-1] + 1
```

You get the extension "for free" and both strings advance.

## The mismatch case

If they differ, the character cannot be part of the same common subsequence. So
one of them is "wasted":

```
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

Drop a character from `text1` or from `text2` and keep whichever gives the longer
LCS.

## Base cases

If either string is empty, the LCS is empty, so the first row and first column
are all `0`. Build the table from the top-left corner outward, and the answer is
`dp[m][n]`.

:::tip
The two-string table is the backbone of a huge family of problems — edit
distance, wildcard matching, distinct subsequences. Get comfortable with *match
→ advance both; mismatch → take the better drop*, and you can adapt it anywhere.
:::
