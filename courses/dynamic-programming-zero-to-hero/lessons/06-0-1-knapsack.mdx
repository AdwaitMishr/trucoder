solution: |
  def solve(weights: list[int], values: list[int], capacity: int) -> int:
      dp = [0] * (capacity + 1)
      for i in range(len(weights)):
          for w in range(capacity, weights[i] - 1, -1):
              dp[w] = max(dp[w], dp[w - weights[i]] + values[i])
      return dp[capacity]

The first problem where one number is not enough to describe the state. You need
to know *which items are used* and *how much capacity remains*. This introduces
the **two-dimensional DP table** — the jump that unlocks the hardest DP problems.

## Why one index is not enough

If you only track capacity, you cannot know which items are already used. So the
state must be a pair: `(item index, remaining capacity)`. The table is
`dp[i][w]` = max value using the first `i` items with at most `w` weight.

## The choice: take or skip item i

For each item `i` and capacity `w`, you either:

- **Skip item `i`** — keep `dp[i-1][w]`.
- **Take it** (if it fits) — `dp[i-1][w - weights[i]] + values[i]`.

Take the better option. This is the "0/1" — each item is used at most once.

```
dp[i][w] = max(dp[i-1][w], dp[i-1][w - weights[i]] + values[i])   if weights[i] <= w
dp[i][w] = dp[i-1][w]                                             otherwise
```

## The space optimization (the classic trick)

Row `i` only depends on row `i-1`. So you can use a single 1D array and iterate
capacity **backwards** (`w` from high to low).

:::warning
The backward direction is not optional. If you loop capacity forward, you reuse
the same item multiple times — that is *unbounded* knapsack. Going backward means
`dp[w - weights[i]]` still holds the value from the *previous* item's row, which
is exactly what 0/1 requires.
:::

:::tip
"Two dimensions: item and capacity" is the template for a whole family of
problems — subset sum, partition equal subset sum, target sum. Learn the shape
once and you can recognize it everywhere.
:::
