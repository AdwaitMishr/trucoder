# How to use this course

Quick-revision resource for the **System Design** section of your placement
prep (section 6 of `interview prep/TODO.md`). It covers both **HLD**
(high-level design — the whiteboard architecture round) and **LLD**
(low-level design — classes and code).

Every lesson: concept → key points → **Use case** → flowchart → **worked
numerical** → **interview questions** → quiz. The design lessons follow the
interview answer shape: *clarify → estimate → APIs → data model → scale →
tradeoffs*.

Lessons **in order**:

1. **Scaling Fundamentals & Estimation** — horizontal vs vertical, CAP, ACID vs BASE, latency vs throughput, the back-of-envelope toolkit (QPS, storage, cache 80/20, servers, bandwidth, availability).
2. **Core Components** — load balancers, caching (Redis, eviction), CDN, SQL vs NoSQL in design.
3. **Async & Scaling Tools** — message queues (Kafka vs SQS vs RabbitMQ), consistent hashing, sharding & replication, rate limiting (token bucket code exercise).
4. **Design: URL Shortener** — the canonical first design (base62 code exercise).
5. **Design: Chat System** — WebSockets, presence, message storage (WhatsApp-style).
6. **Design: News Feed** — fanout push/pull/hybrid, caching, ranking (Twitter/Instagram-style).
7. **Design: Notification System** — queues, workers, providers, retries (Meta/Uber/Swiggy-style).
8. **Design: Streaming & Ride-Sharing** — CDN/DASH (Netflix) and geo-matching (Uber), plus a GenAI/RAG bonus.
9. **Low-Level Design Practice** — SOLID, pattern selection, classic LLD problems, snake & ladder BFS code exercise.
10. **Final Assessment** — comprehensive MCQ/MSQ exam across all nine lessons.
