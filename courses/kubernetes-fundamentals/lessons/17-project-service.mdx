    content: |
      The Deployment creates pods; the **Service** gives them a stable
      address. For ShopAPI:

      ```yaml
      apiVersion: v1
      kind: Service
      metadata:
        name: shop-api
      spec:
        type: ClusterIP
        selector:
          app: shop-api
        ports:
          - port: 80            # what clients connect to
            targetPort: 8080    # where the pod actually listens
      ```

      Two numbers, constantly confused:

      - `port` — the Service's own port (what the DNS name resolves to).
      - `targetPort` — the container port on the pod (must match
        `containerPort` in the Deployment).

      The selector must match the pod labels from the Deployment —
      `app: shop-api` on both. Mismatch = a Service with zero endpoints.

      ```bash
      kubectl get svc shop-api
      kubectl get endpoints shop-api      # empty = selector problem
      kubectl describe svc shop-api
      ```

      :::tip
      A NodePort service adds a third number: `nodePort` (30000–32767), a
      port opened on EVERY node that forwards to `port`. The task's
      `node_port` slot is None for ClusterIP services.
      :::

      :::warning
      Endpoints are the ground truth: `kubectl get endpoints` lists the
      pod IPs behind a Service. Empty endpoints with a running Deployment
      almost always mean the selector does not match the pod labels.
      :::

    hints:
      - "Parse pod_labels by splitting on ',' then '=' to build a dict."
      - "selector_ok requires EVERY selector key to be in the pod labels dict with the same value."
      - "Use .get('nodePort') — missing means None."
    solution: |
      import yaml

      def solve(manifest: str, pod_labels: str) -> list:
          d = yaml.safe_load(manifest)
          spec = d["spec"]
          selector = spec.get("selector", {})
          labels = {}
          for pair in pod_labels.split(","):
              if pair:
                  k, v = pair.split("=", 1)
                  labels[k] = v
          selector_ok = all(labels.get(k) == v for k, v in selector.items())
          p = spec["ports"][0]
          return [p["port"], p["targetPort"], p.get("nodePort"), selector_ok]
