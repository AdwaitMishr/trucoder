  - type: markdown
    content: |
      ShopAPI writes weekly reports to `/data`. The last manifest:

      ```yaml
      apiVersion: v1
      kind: PersistentVolumeClaim
      metadata:
        name: shop-reports
      spec:
        accessModes:
          - ReadWriteOnce
        resources:
          requests:
            storage: 1Gi
      ```

      And the Deployment side (from lesson 16):

      ```yaml
                volumeMounts:
                  - name: reports
                    mountPath: /data
            volumes:
              - name: reports
                persistentVolumeClaim:
                  claimName: shop-reports
      ```

      The wiring has three names that must agree: the volume's `name`
      (`reports`), the mount's `name` (`reports`), and the claim's
      `claimName` (`shop-reports` — which must match the PVC's
      `metadata.name`).

      :::warning
      `ReadWriteOnce` = one node at a time. ShopAPI runs 3 replicas but
      only ONE mounts the PVC (a sidecar pattern). Mounting an RWO claim
      from every replica leaves the others stuck in ContainerCreating.
      :::

      :::tip
      This is the classic interview question: "how do you give state to a
      stateless deployment?" The answer is the claim + mount pair — the
      deployment stays a Deployment, the state lives behind a PVC.
      :::

    hints:
      - "Branch on kind — PersistentVolumeClaim vs Deployment."
      - "For the Deployment, find the first volume that has a persistentVolumeClaim key, then match its name against volumeMounts."
      - "storageClassName is optional — use .get()."
    solution: |
      import yaml

      def solve(manifest: str) -> list:
          d = yaml.safe_load(manifest)
          if d["kind"] == "PersistentVolumeClaim":
              spec = d["spec"]
              return [
                  "pvc",
                  spec["resources"]["requests"]["storage"],
                  spec["accessModes"],
                  spec.get("storageClassName"),
              ]
          spec = d["spec"]
          vols = spec["template"]["spec"].get("volumes", [])
          claim = None
          vname = None
          for v in vols:
              if "persistentVolumeClaim" in v:
                  vname = v["name"]
                  claim = v["persistentVolumeClaim"]["claimName"]
                  break
          mount = None
          if vname:
              for m in spec["template"]["spec"]["containers"][0].get("volumeMounts", []):
                  if m["name"] == vname:
                      mount = m["mountPath"]
                      break
          return ["deployment", claim, mount]
