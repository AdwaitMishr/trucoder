    content: |
      Outside traffic needs a door, and load needs a brain. For ShopAPI:

      ```yaml
      apiVersion: networking.k8s.io/v1
      kind: Ingress
      metadata:
        name: shop-ingress
      spec:
        ingressClassName: nginx
        rules:
          - host: shop.example.com
            http:
              paths:
                - path: /
                  pathType: Prefix
                  backend:
                    service:
                      name: shop-api
                      port:
                        number: 80
      ```

      ```yaml
      apiVersion: autoscaling/v2
      kind: HorizontalPodAutoscaler
      metadata:
        name: shop-api-hpa
      spec:
        scaleTargetRef:
          apiVersion: apps/v1
          kind: Deployment
          name: shop-api
        minReplicas: 2
        maxReplicas: 6
        metrics:
          - type: Resource
            resource:
              name: cpu
              target:
                type: Utilization
                averageUtilization: 70
      ```

      The HPA watches the Deployment's average CPU. Above 70% it adds
      replicas (up to 6); below, it removes them (down to 2).

      :::warning
      The HPA needs a `requests.cpu` on the container — the utilization
      percentage is computed against the request, not the limit. No
      request = the HPA cannot calculate utilization.
      :::

      :::tip
      Ingress backends reference a Service by name + port number — the
      same Service you validated in the previous lesson. The three pieces
      (Deployment labels → Service selector → Ingress backend) must name
      the same things or the chain breaks silently.
      :::

    hints:
      - "Branch on d['kind'] — 'Ingress' vs 'HorizontalPodAutoscaler'."
      - "The first rule is at spec.rules[0]; its first path at spec.rules[0].http.paths[0]."
      - "For the HPA, the target percentage lives at spec.metrics[0].resource.target.averageUtilization."
    solution: |
      import yaml

      def solve(manifest: str) -> list:
          d = yaml.safe_load(manifest)
          kind = d["kind"]
          if kind == "HorizontalPodAutoscaler":
              spec = d["spec"]
              target = spec["metrics"][0]["resource"]["target"]["averageUtilization"]
              return ["hpa", spec["minReplicas"], spec["maxReplicas"], target]
          spec = d["spec"]
          rule = spec["rules"][0]
          path = rule["http"]["paths"][0]
          backend = path["backend"]["service"]
          tls = spec.get("tls")
          secret = tls[0].get("secretName") if tls else None
          return ["ingress", rule["host"], path["path"], backend["name"], backend["port"]["number"], secret]
