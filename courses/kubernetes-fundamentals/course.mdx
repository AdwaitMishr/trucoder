# How to use this course

Kubernetes sounds like a wall of acronyms: Pods, Deployments, Services, HPAs.
Strip the jargon away and it is a small set of *ideas* — and every idea is
either a command you run or a number you reason about.

Most lessons here are **reading**: the concept, the `kubectl` commands, and the
YAML that makes it real. Read them like the docs you wish existed — then run
the commands on a cluster (or `minikube`/`kind` on your laptop) to make them
stick. Two lessons are **coding exercises**, kept only where the math is
genuinely worth practicing: resource units and HPA math.

Work through the lessons **in order**:

1. Cluster architecture — who is who, and how `kubectl` talks to it.
2. Pods — the smallest unit Kubernetes schedules.
3. Resource units — what `128Mi` actually means (code).
4. Deployments — desired state, replicas, rolling updates.
5. Services — stable names, selectors, DNS.
6. Probes — readiness vs liveness, and the timing math.
7. HPA math — the autoscaler's formula (code).
8. Taints & tolerations — who is allowed on which node.

By the end you will read a Deployment manifest and see *why* every number is
there — and you will know the command to type when something misbehaves.
