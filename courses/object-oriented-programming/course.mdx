# How to use this course

Quick-revision resource for the **C++ & OOP** section of your placement prep
(section 1 of `interview prep/TODO.md`). Every lesson: concept → key points →
**Use case** → flowchart → **interview questions** → quiz. The coding
exercises are in **C++** (plus Python/JS equivalents) because this course is
about C++ OOP.

Lessons **in order**:

1. **Classes & Objects** — classes, access specifiers, constructors/destructors, `this`, static members.
2. **Encapsulation & Abstraction** — access control, abstract classes, interfaces, friend functions.
3. **Inheritance** — all 5 types, the diamond problem, virtual inheritance.
4. **Polymorphism** — compile-time (overloading), runtime (virtual functions), vtable/vptr.
5. **Copy Semantics & Memory** — copy vs assignment, deep vs shallow, Rule of 3/5, stack vs heap, `new`/`delete`, leaks.
6. **Modern C++ & STL** — smart pointers, RAII, containers & algorithms, const correctness, move semantics.
7. **Modern C++ Deep Dive** — auto, structured bindings, optional/variant, lambdas vs std::function, concurrency (threads, mutex, atomics, data races).
8. **Design Patterns (interview edition)** — Singleton (and why it's an anti-pattern), Factory, Observer, Strategy, SOLID.
9. **Final Assessment** — interview-favourite questions + comprehensive MCQ/MSQ exam.
