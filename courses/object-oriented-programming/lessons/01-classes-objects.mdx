      ### Class vs Object

      - **Class** — a *blueprint*: it declares what data (members) and what
        behavior (methods) an object will have. Defining a class allocates no
        memory.
      - **Object** — a concrete *instance* of a class, created at runtime; it
        occupies memory and holds its own copy of the data members.
      - One class → many objects: `Circle c1(1.0), c2(2.0);` — same blueprint,
        independent state.

      **Access specifiers** control who can see what:

      - `public` — accessible from anywhere.
      - `private` — only the class's own member functions (and friends).
      - `protected` — private outside, but accessible in derived classes.

      **Use case:** `BankAccount` is the blueprint (balance, account id,
      `withdraw()`/`deposit()`); every customer's account is an object with
      its own balance.

      ### Constructors & destructors

      - **Default ctor** — no arguments; auto-generated *only if you define no
        constructor at all*.
      - **Parameterized ctor** — takes arguments to initialize the object:
        `BankAccount acc("1234", 1000);`
      - **Copy ctor** — `BankAccount b2 = b1;` builds a *new* object as a copy
        of an existing one: `BankAccount(const BankAccount& other);`
      - **Destructor** — `~BankAccount()` runs automatically when the object
        goes out of scope (or is `delete`d); used to release resources.

      **Constructor initializer list** — members are initialized *before* the
      body runs; the only way to initialize `const` and reference members:

      ```cpp
      BankAccount::BankAccount(std::string id, double bal)
          : id_(std::move(id)), balance_(bal) {}
      ```

      **Use case:** a `GameEntity` constructor acquires a texture handle; its
      destructor releases it — no matter how the object dies, the resource is
      freed (RAII in one line).

      ### `this`, static members, const methods

      - **`this`** — a hidden pointer to the object the member function was
        called on.
        - Resolves **name shadowing**: `this->radius = radius;`
        - Enables **method chaining**: return `*this` from setters.
      - **Static members** (`static int count;`) — belong to the *class*, not
        to any object: **one shared copy** across all objects; defined once
        outside the class.
      - **Static member functions** — called as `ClassName::fn()` without an
        object; they have **no `this`**, so they can only touch static members.
      - **`const` member functions** (`double area() const`) — promise not to
        modify the object; required to call methods on `const` objects.

      **Use case:** a `static int liveObjects` counter incremented in the
      constructor and decremented in the destructor; a `Config` class exposing
      one shared settings object via a static member.

      :::tip
      **Interview question:** what is a static member function and can it access
      instance members? — It belongs to the class, not to an instance: it has no
      `this` pointer, so it can only access static members; to read an instance
      member it must be passed an explicit object.
      :::
  - type: markdown
    content: |
      ### **Interview questions**

      :::tip
      **Interview question:** when is the copy constructor called? — When a
      *new* object is initialized from an existing one: `B b2 = b1;`, passing
      an object by value, or returning by value (copy elision aside). Plain
      assignment `b2 = b1;` is **copy assignment**, not the copy constructor.
      :::

      - Copy ctor signature: `BankAccount(const BankAccount& other);`
      - Pass by `const&` to avoid needless copies.
      - If you write any constructor yourself, the default constructor is not
        auto-generated.

      import math

      class Circle:
          def __init__(self, r):
              self.r = r

          def area(self):
              return math.pi * self.r * self.r

      def solve(radius: float) -> str:
          return f"{Circle(radius).area():.2f}"
